# Legacy Archive

This folder keeps files that are not part of the current production runtime but may still be useful as history, references, or future experiments.

## What Was Moved

### `patch-snapshots/page_conflict_fix_patch`

Old page conflict patch snapshot. The active frontend page is now:

- `frontend/app/page.tsx`

### `frontend-default-assets`

Default SVG assets generated by the initial Next.js scaffold:

- `file.svg`
- `globe.svg`
- `next.svg`
- `vercel.svg`
- `window.svg`

The current app does not reference these files.

### `experimental-transformer`

Transformer fine-tuning experiments and planning notes. The deployed system currently uses the lightweight TF-IDF based `symptom_classifier.pkl` model for stable inference.

Active model pipeline:

- `data_pipeline/symptom_model/train_symptom_classifier.py`
- `data_pipeline/symptom_model/evaluate_symptom_classifier.py`
- `models/symptom_classifier.pkl`

### `unused-services/llm_service.py`

Earlier optional LLM helper module. The current disease prediction and triage question flow does not import it. The service now keeps LLM usage out of the core diagnosis path and relies on the trained classifier plus curated question map.

## Restore Guidance

If any archived item becomes useful again, move it back into the active source tree and re-run:

```bash
python -m py_compile backend/services/*.py
cd frontend
npm run lint
npm run build
```
