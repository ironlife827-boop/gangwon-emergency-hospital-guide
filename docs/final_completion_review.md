# 최종 완성도 점검

## 최종 시스템 요약

이 프로젝트는 강원도 맞춤형 응급 및 상시 병원 안내 웹 서비스다. 사용자가 자연어로 증상을 입력하면 네이버 지식인 기반 증상 사례 데이터로 학습한 `symptom_classifier.pkl`이 증상군, 추천 진료과, 의심 질환을 먼저 예측한다. 이후 질환별 문진 DB에서 필요한 질문만 1~4개 선택하고, 최초 증상과 문진 답변을 합쳐 최종 질환을 재판정한 뒤 응급도와 추천 병원을 제공한다.

## 기존 부족점과 보강 결과

| 구분 | 기존 부족점 | 최종 보강 |
| --- | --- | --- |
| 증상-질환 연결 | 병원 추천은 있었지만 자연어 증상과 진료과/질환을 연결하는 모델 근거가 약했다. | `symptom_classifier.pkl`을 핵심 판단 모델로 사용하고, `symptom_group`, `department`, `suspected_disease`를 각각 예측한다. |
| 라벨 커버리지 | 기존 질환 수가 적어 뇌진탕, 노로바이러스, 고열 동반 호흡곤란, 감기 같은 입력이 엉뚱한 질환으로 밀릴 수 있었다. | 학습 데이터 3,499건, 의심 질환 121개, 증상군 20개, 진료과 18개로 확장했다. |
| 크롤링 품질 | 비의료성 사례가 섞일 위험이 있었다. | `naver_crawl_query_plan.csv` 기반으로 재수집하고, 동물/꿈/법률/광고/비의료 사례를 필터링했다. |
| 문진 질문 | 고정 질문 또는 증상군 질문이 섞일 수 있었다. | `disease_question_map.csv`를 81질환/397문항으로 보강하고, 질환 일치 점수를 가장 크게 반영한다. |
| 오분류 보정 | 키워드 하나만 보고 익수, 노로바이러스, 열사병 등으로 튀는 문제가 있었다. | 고위험 앵커 조건을 강화해 해산물 단서 없는 고열/두통은 수막염 의심 쪽으로, 더위 노출 없는 고열은 열사병으로 과보정되지 않게 했다. |
| 상시 진료 질환 | 감기, 독감, 코로나19 같은 경증 호흡기 증상이 응급질환으로 강제 분류될 수 있었다. | 상시 병원 안내 질환 라벨과 문진 질문을 추가해 경증/상시 진료와 응급 진료를 분리했다. |
| 병원 추천 | 거리가 가까운 병원이 병상 0개여도 우선 노출될 수 있었다. | 가용 병상, 응급실 여부, 진료과 매칭, 이동시간을 함께 점수화하고, 병상 0개 병원은 큰 패널티를 받게 했다. |
| 평가 근거 | 단순 구현 위주라 모델 성능 비교 근거가 부족했다. | baseline, word TF-IDF, char TF-IDF, Linear SVC 모델을 비교하고 평가 리포트를 생성했다. |
| 화면 완성도 | 추천 점수처럼 사용자에게 불필요한 정보가 보일 수 있었다. | 화면은 응급도, 의심 질환, 진료과, 병원, 경로, 병상 중심으로 간결하게 구성했다. |
| 상시 병원 안내 | 3~5단계 일반 증상도 응급실/병상 중심으로 추천될 수 있었다. | 1~2단계는 응급실/병상 우선, 3~5단계는 일반 병원/의원과 진료과/거리 우선으로 추천하도록 분리했다. |

## 최종 데이터와 모델

- 학습 데이터: `data/processed/naver_kin_symptom_cases.csv`
- 전체 학습 사례: 3,499건
- 증상군: 20개
- 진료과: 18개
- 의심 질환: 121개
- 문진 질문 DB: 126질환, 532문항
- 재수집 후보: 450건
- 필터 통과 재수집 데이터: 432건
- 필터 제외 데이터: 18건

| Target | Best model | Accuracy | Macro F1 | Weighted F1 |
| --- | --- | ---: | ---: | ---: |
| symptom_group | char_tfidf_linear_svc | 0.9871 | 0.9827 | 0.9876 |

## 최종 회귀 테스트 입력

- `오른쪽 팔 감전` -> 전기손상
- `갑자기 왼팔에 힘이 안 들어가고 말이 어눌해요` -> 뇌졸중
- `벌에 쏘인 뒤 입술이 붓고 숨쉬기 힘들어요` -> 아나필락시스
- `배가 찢어질 듯 아프고 식은땀이 나요` -> 복막염 계열
- `가슴이 답답하고 숨이 차요` -> 급성 심근경색 계열
- `갑자기 열이 40도까지 나고 숨쉬는게 힘들어요` -> 고열 동반 호흡곤란
- `굴을 잘못 먹고 토하고 설사해요` -> 노로바이러스 의심 급성 위장염
- `작업하다가 사다리에 머리를 맞아 3초간 기절한 상태다` -> 뇌진탕 의심 두부손상
- `머리가 심하게 아프고 열이 38.5도이며 진통제를 먹어도 낫지 않음` -> 수막염 의심
- `목이 아프고 콧물이 나며 기침이 있고 37.5도 미열` -> 감기
- `39도 고열과 몸살, 심한 기침` -> 독감
- `열, 기침, 후각 저하` -> 코로나19
- `감기 문진 위험 신호 모두 아니오` -> 5단계 비응급, 주변 일반 병원 우선 추천

## 남은 한계

- 실제 의료 판단을 대체할 수 없으며 응급 상황에서는 119 또는 의료진 판단이 우선이다.
- 모델 평가는 같은 출처의 train/test split 기반이므로, 사람 검수 독립 테스트셋이 있으면 더 강한 근거가 된다.
- 공공 병상 API 또는 길찾기 API 장애 시 정적 데이터와 거리 기반 추정으로 fallback한다.
- TF-IDF 기반 모델은 빠르고 안정적이지만 문맥 이해에는 한계가 있으므로, 운영 안정성을 유지하면서 별도 Transformer 모델은 추후 고도화 후보로 남긴다.

## 결론

교수님 피드백의 핵심이었던 `증상 자연어 -> 진료과/질환 매칭 모델`이 구현되었고, 데이터 수집/정제, 모델 비교, 동적 문진, 위험도 계산, 병원 추천, 유사 사례 링크가 하나의 웹 서비스 흐름으로 연결되었다. 현재 상태는 기능 시연과 프로젝트 평가 기준 대응이 가능한 최종 완성본이다.
